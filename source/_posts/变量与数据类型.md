## 基本数据类型

Java 有 8 种基本数据类型（primitive types）：

| 类型 | 大小 | 默认值 | 取值范围 |
| --- | --- | --- | --- |
| byte | 1 字节 | 0 | -128 ~ 127 |
| short | 2 字节 | 0 | -32768 ~ 32767 |
| int | 4 字节 | 0 | -2^31 ~ 2^31-1 |
| long | 8 字节 | 0L | -2^63 ~ 2^63-1 |
| float | 4 字节 | 0.0f | 单精度浮点 |
| double | 8 字节 | 0.0d | 双精度浮点 |
| char | 2 字节 | '\u0000' | 0 ~ 65535 |
| boolean | - | false | true / false |

## 声明变量

```java
public class Demo {
    public static void main(String[] args) {
        int age = 18;              // 整型
        double price = 9.99;       // 浮点型
        char grade = 'A';          // 字符型
        boolean flag = true;       // 布尔型
        String name = "yzy212";    // 引用类型

        System.out.println(age);
        System.out.println(price);
        System.out.println(grade);
        System.out.println(flag);
        System.out.println(name);
    }
}
```

## 小结

- 整型默认是 `int`，浮点默认是 `double`
- `long` 类型字面量末尾加 `L`，`float` 加 `f`
- `String` 不是基本类型，是引用类型
