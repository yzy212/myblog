从安装 JDK 到运行第一个 Java 程序。

## 1. 安装 JDK

JDK（Java Development Kit）是 Java 开发工具包，包含编译器和运行环境。

**下载安装：**

1. 打开 Oracle 官网下载页（搜 "JDK download"），或使用开源的 OpenJDK
2. 选择对应系统（Windows / macOS / Linux）的安装包
3. 一路下一步安装即可

**验证是否装好：** 打开终端（命令行），输入：

```bash
java -version
javac -version
```

如果输出类似下面的版本号，说明装好了：

```
java version "17.0.8" ...
javac 17.0.8
```

> 如果提示「不是内部或外部命令」，说明环境变量 `JAVA_HOME` 和 `PATH` 没配好。可以搜 "Windows 配置 Java 环境变量" 按教程设置。

## 2. 第一个程序 Hello World

新建一个文件 `Hello.java`，内容如下：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

**编译和运行**（在文件所在目录打开终端）：

```bash
# 编译：把 .java 源码编译成 .class 字节码
javac Hello.java

# 运行：执行编译后的类
java Hello
```

输出：

```
Hello, Java!
```

## 3. 程序结构详解

把上面的代码拆开看：

```java
public class Hello {                      // ① 类声明：类名 Hello 必须和文件名一致
    public static void main(String[] args) {   // ② main 方法：程序入口
        System.out.println("Hello, Java!");    // ③ 方法体：要执行的语句
    }
}
```

- **① `public class Hello`**：定义一个公开的类，类名 `Hello` 要和文件名 `Hello.java` 一致
- **② `public static void main(String[] args)`**：`main` 方法是程序的入口，固定写法
- **③ 语句**：以分号 `;` 结尾，`System.out.println` 是打印并换行

`main` 方法的每个关键字含义：

| 关键字 | 含义 |
| --- | --- |
| public | 公开的，可被外部访问 |
| static | 静态的，无需创建对象即可调用 |
| void | 没有返回值 |
| String[] args | 命令行参数（字符串数组） |

## 4. 几个常用输出语句

```java
public class PrintDemo {
    public static void main(String[] args) {
        System.out.println("打印并换行");
        System.out.print("打印不换行");
        System.out.print("，接着上一行");
        System.out.println();

        // 拼接输出
        int age = 18;
        String name = "小明";
        System.out.println(name + "今年" + age + "岁");
    }
}
```

输出：

```
打印并换行
打印不换行，接着上一行
小明今年18岁
```

## 小结

- 装好 JDK，配好环境变量，`java -version` 能输出版本号即可
- 写代码 → `javac` 编译 → `java` 运行
- 类名要和文件名一致，`main` 方法固定写法
