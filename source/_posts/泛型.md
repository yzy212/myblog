泛型让类或方法可以处理「任意类型」，同时保证类型安全。常见的 `<T>`、`List<String>` 里的 `<>` 就是泛型。

## 1. 为什么需要泛型

没有泛型时，集合里什么都往里放，取出来还要强转，容易出错。

```java
import java.util.ArrayList;
import java.util.List;

public class NoGenericDemo {
    public static void main(String[] args) {
        // 没有泛型（不推荐）
        List list = new ArrayList();
        list.add("hello");
        list.add(123);   // 能放任意类型

        // 取出来是 Object，要强转，容易 ClassCastException
        String s = (String) list.get(0);
        System.out.println(s);
    }
}
```

用了泛型后，类型在编译期就确定了。

```java
List<String> list = new ArrayList<>();
list.add("hello");
// list.add(123);   // 编译报错：不能放 Integer
String s = list.get(0);   // 不用强转
```

## 2. 泛型类

```java
// Box<T>：T 是类型参数，使用时指定具体类型
public class Box<T> {
    private T value;

    public void set(T value) {
        this.value = value;
    }

    public T get() {
        return value;
    }
}
```

```java
public class GenericClassDemo {
    public static void main(String[] args) {
        Box<String> strBox = new Box<>();
        strBox.set("hello");
        System.out.println(strBox.get());   // hello

        Box<Integer> intBox = new Box<>();
        intBox.set(100);
        System.out.println(intBox.get());   // 100
    }
}
```

同一个 `Box` 类，可以装 `String`，也可以装 `Integer`，类型安全。

## 3. 泛型方法

```java
import java.util.List;

public class GenericMethodDemo {
    // <T> 声明这是一个泛型方法
    public static <T> T getFirst(List<T> list) {
        return list.get(0);
    }

    public static void main(String[] args) {
        List<String> names = List.of("Java", "Python", "C++");
        List<Integer> nums = List.of(1, 2, 3);

        String first = getFirst(names);   // 返回 String
        int n = getFirst(nums);           // 返回 Integer

        System.out.println(first);   // Java
        System.out.println(n);       // 1
    }
}
```

## 4. 通配符 ?

```java
import java.util.List;

public class WildcardDemo {
    // List<?>：任意类型的 List
    public static void printList(List<?> list) {
        for (Object o : list) {
            System.out.println(o);
        }
    }

    public static void main(String[] args) {
        printList(List.of("a", "b", "c"));
        printList(List.of(1, 2, 3));
    }
}
```

`?` 表示未知类型。更细的区分：

- `<? extends Number>`：Number 或其子类（上界）
- `<? super Integer>`：Integer 或其父类（下界）

## 5. 多个类型参数

```java
// 键值对，两个类型参数
public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }
}
```

```java
public class PairDemo {
    public static void main(String[] args) {
        Pair<String, Integer> pair = new Pair<>("Java", 100);
        System.out.println(pair.getKey() + " -> " + pair.getValue());   // Java -> 100
    }
}
```

## 小结

- 泛型让代码能处理任意类型，且编译期检查类型安全
- 泛型类：`class Box<T>`，泛型方法：`<T> T method(...)`
- `?` 通配符表示未知类型，`? extends` 上限，`? super` 下限
