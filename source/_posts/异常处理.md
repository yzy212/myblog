程序运行时出问题会抛「异常」。用 `try-catch` 可以捕获并处理，避免程序崩溃。

## 1. 常见异常

| 异常 | 触发场景 |
| --- | --- |
| NullPointerException | 调用 null 对象的方法 |
| ArrayIndexOutOfBoundsException | 数组下标越界 |
| ArithmeticException | 除零等算术错误 |
| NumberFormatException | 字符串转数字格式不对 |
| ClassCastException | 类型转换错误 |

```java
public class ExceptionDemo {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3};
        System.out.println(arr[5]);   // 数组越界，抛 ArrayIndexOutOfBoundsException
    }
}
```

## 2. try-catch 捕获异常

```java
public class TryCatchDemo {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3};
            System.out.println(arr[5]);   // 这里抛异常
            System.out.println("这行不会执行");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("捕获到数组越界异常：" + e.getMessage());
        }

        System.out.println("程序继续执行");
    }
}
```

输出：

```
捕获到数组越界异常：Index 5 out of bounds for length 3
程序继续执行
```

## 3. 多个 catch 和 finally

```java
public class MultiCatchDemo {
    public static void main(String[] args) {
        try {
            String s = null;
            System.out.println(s.length());   // 空指针异常
        } catch (NullPointerException e) {
            System.out.println("空指针了");
        } catch (Exception e) {               // 兜底：捕获其他异常
            System.out.println("其他异常：" + e);
        } finally {
            // finally 无论是否有异常都会执行
            System.out.println("finally 总会执行");
        }
    }
}
```

要点：
- `catch` 从上到下匹配，子类异常写在父类前面
- `finally` 无论是否异常都会执行，常用来释放资源

## 4. throw 和 throws

- `throw`：主动抛出异常
- `throws`：声明方法可能抛出的异常，让调用者处理

```java
public class ThrowDemo {
    // throws 声明：这个方法可能抛 ArithmeticException
    public static int divide(int a, int b) throws ArithmeticException {
        if (b == 0) {
            // throw 主动抛出
            throw new ArithmeticException("除数不能为 0");
        }
        return a / b;
    }

    public static void main(String[] args) {
        try {
            System.out.println(divide(10, 2));   // 5
            System.out.println(divide(10, 0));   // 抛异常
        } catch (ArithmeticException e) {
            System.out.println("出错了：" + e.getMessage());
        }
    }
}
```

## 5. 自定义异常

继承 `Exception`（受检异常）或 `RuntimeException`（运行时异常）。

```java
// 自定义异常
public class AgeException extends Exception {
    public AgeException(String message) {
        super(message);
    }
}
```

```java
public class CustomExceptionDemo {
    public static void checkAge(int age) throws AgeException {
        if (age < 0 || age > 150) {
            throw new AgeException("年龄不合法：" + age);
        }
        System.out.println("年龄合法");
    }

    public static void main(String[] args) {
        try {
            checkAge(25);    // 年龄合法
            checkAge(-5);    // 抛异常
        } catch (AgeException e) {
            System.out.println("捕获：" + e.getMessage());
        }
    }
}
```

## 6. try-with-resources（自动关闭资源）

处理文件、网络等需要「关闭」的资源时，可以自动关闭。

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class TryResourceDemo {
    public static void main(String[] args) {
        // 括号里声明的资源会自动关闭，不用手动 close
        try (BufferedReader reader = new BufferedReader(new FileReader("test.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.out.println("读取文件失败：" + e.getMessage());
        }
    }
}
```

## 小结

- 异常用 `try-catch-finally` 捕获处理
- `throw` 抛异常，`throws` 声明异常
- `finally` 总会执行，`try-with-resources` 自动关资源
- 自定义异常继承 `Exception` 或 `RuntimeException`
